# OpenTypeless 数据位置与备份说明

> 版本：v0.9 草案（路径以 `AppPathsService` 实现为准）

## 1. 数据根目录

```
~/Library/Application Support/<bundle-id>/
```

其中 `<bundle-id>` 为应用标识（开发构建为 `dev.opentypeless.app`，正式版以 REL-001 签名为准）。目录创建权限为 `0700`（仅当前用户可访问）。「设置 → 数据与存储 → 打开数据目录」可直接跳转。

## 2. 目录结构

| 路径 | 内容 | 说明 |
| --- | --- | --- |
| `opentypeless.sqlite` | 主数据库 | 历史记录、词典、模型配置（含 API 密钥）、应用设置 |
| `recordings/` | 全部录音（`.m4a`） | 数据库只保存相对路径，整体移动数据根目录后可重新定位 |
| `tmp/` | 录音中的半成品（`.partial`） | 正常停止后改名为正式文件；异常退出后由启动恢复处理 |
| `logs/` | 运行日志 | 经脱敏处理，不含完整密钥与完整口述文字 |
| `backups/` | 预留的备份目录 | 当前版本**暂无自动备份**，重要数据请按下节手动备份 |

## 3. 备份

- **手动备份**：退出应用后，整体复制数据根目录即可。注意备份**包含 API 密钥**，请妥善保管备份文件。
- **只需备份录音与历史**：复制 `opentypeless.sqlite` 与 `recordings/` 两个即可。
- 应用不自动上传任何数据，也没有云同步。

## 4. 迁移到新 Mac

1. 旧 Mac 退出 OpenTypeless，复制整个数据根目录。
2. 新 Mac 安装 OpenTypeless 并启动一次后退出。
3. 用旧目录整体替换新 Mac 的同名目录（保持权限为仅当前用户）。
4. 重新启动。数据库时间为 UTC 存储，跨时区显示与统计自动正确。

## 5. 删除与卸载

- 删除单条记录：在历史中删除（二次确认），同时移除录音文件。
- 批量清理：「设置 → 数据与存储 → 清理 N 天前的记录」（二次确认），这是唯一的批量删除入口。
- 完全卸载：删除 `.app` 后，再删除整个数据根目录。此操作不可撤销。

## 6. 密钥安全说明

- API 密钥以明文保存在本机 SQLite 中（后续版本再设计加密存储），因此**目录权限与备份保管是关键防线**：不要降低数据目录权限，不要把数据库文件发给他人。
- 界面只显示掩码密钥；日志、导出、错误提示均经脱敏。
- 如怀疑密钥泄露：先在服务方后台吊销并更换密钥，再在「设置 → 模型」中更新。
