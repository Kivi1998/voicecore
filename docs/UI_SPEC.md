# 界面与交互实现规范

所有视觉决策以根目录 `DESIGN.md` 为最高依据。本文件只补充具体页面交互和工程验收，不重复发明颜色、字体、材质和圆角。

## 1. 实现边界

- 主界面使用 SwiftUI，macOS 专属窗口、菜单栏、非激活浮层和系统集成使用 AppKit。
- 禁止使用 React、Vue、Tauri、Electron 或 WKWebView 作为主界面。
- 优先使用系统 `NavigationSplitView`、`List`、`Table`、`Form`、`Settings`、`Toolbar`、`Menu`、`Sheet` 和 `Popover`。
- 自定义控件只用于系统控件无法表达的录音胶囊、输入电平和明确的产品状态。
- 业务视图不得直接调用 AppKit；通过平台服务协议和可观察状态接入。

## 2. Liquid Glass

- 支持的系统使用 SwiftUI/AppKit 原生 Liquid Glass API；禁止用自绘渐变、模糊和高光代替。
- 旧系统使用 SwiftUI `Material` 或 AppKit `NSVisualEffectView`。
- 玻璃只用于导航、工具栏、录音胶囊、弹出控制和少量关键按钮。
- 历史正文、设置表单和统计内容区域使用稳定内容材质。
- 必须测试窗口激活/未激活、不同桌面背景、浅色/深色、增加对比度、减少透明度和减少动态效果。

## 3. 主窗口

- 采用原生分栏：首页、历史记录、词典。
- 设置使用独立设置场景，并能通过标准应用菜单和快捷键打开。
- 工具栏的搜索、筛选、添加和更多操作遵循系统分组与位置。
- 主窗口默认约 1100×720 点，最小约 860×560 点；缩放时不能丢失主要操作。
- 不显示账户、头像、会员、升级、额度、推广和推荐内容。

## 4. 首页

- 重点展示今日、本周和累计口述量、时长及最近记录。
- 信息分组避免全部卡片化；层级由标题、间距、材质和对齐建立。
- 显示当前快捷键、语音模型和改写模型。
- 趋势图提供 VoiceOver 摘要，并在减少动态效果时取消入场动画。

## 5. 历史记录

- 支持日期范围、全文搜索、状态和收藏筛选。
- 按日期分组，时间列稳定；长文本可选择和复制。
- 正常记录就近提供复制、播放、下载、收藏操作。
- 失败记录明确显示失败阶段、可重试性和主要重试按钮。
- 删除使用系统破坏性角色和二次确认，明确会同时删除录音。
- 原始转录与最终文字标签清楚，改写失败时仍可使用原始转录。

## 6. 词典

- 支持搜索、添加单个词语和删除。
- 添加 Sheet 只包含词语输入、取消和确认。
- 空词与重复词原位提示，不因验证失败关闭 Sheet。

## 7. 设置

- 分为快捷键与录音、语音模型、文字改写、输出、数据与存储、常规。
- 使用原生 Form、Picker、Toggle、SecureField 和帮助文本。
- 密钥默认遮罩，支持替换和清除；完整值不进入普通可观察视图状态。
- 连接测试显示进度、成功或结构化错误，不创建正式历史。
- 数据区显示数据库和录音占用、打开目录、导出和明确范围的手动删除。

## 8. 录音胶囊

- 使用非激活面板或等价 AppKit 窗口承载，不能改变当前应用焦点。
- 按一次快捷键开始，再按一次停止；胶囊状态与持久化状态机一致。
- 录音中显示时长和克制的输入电平；转录、改写不得继续显示录音动画。
- 成功后短暂停留并退出；失败后保留打开历史和重试入口。
- 所有状态具有 VoiceOver 标签；开启减少动态效果时使用淡入淡出替代形变。

## 9. 菜单、键盘与可访问性

- 应用菜单包含关于、设置、服务、隐藏和退出等 macOS 标准项目。
- 常用操作提供菜单命令和键盘等价项；不可只依赖悬停按钮。
- 所有图标来自 SF Symbols 并提供 `accessibilityLabel` 和 Help。
- 支持完整键盘导航、清晰焦点、VoiceOver、增加对比度和不同系统文字设置。
- 颜色不是唯一状态表达；错误必须同时有图标、标题和下一步。

## 10. 验收设备与状态

- Apple 芯片 Mac，macOS 14 基础降级路径。
- 支持 Liquid Glass 的新版 macOS 原生路径。
- 浅色、深色、系统强调色、增加对比度、减少透明度、减少动态效果。
- 主窗口激活与未激活、外接显示器、休眠唤醒、全屏应用和多桌面空间。
- 空历史、长文本、大量历史、模型未配置、无权限、离线、磁盘异常和各阶段失败。
