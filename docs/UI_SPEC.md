# 界面与交互设计规范

## 1. 设计目标

主窗口是安静、可信的统计与记录中心，录音过程则尽量隐形。用户不应为了开始口述而切换窗口。

参考 Typeless 截图中的克制、留白、清晰层级和圆角卡片，但不得复制其品牌、标志、专有文案、插图和像素级布局。

## 2. 视觉原则

- 使用温和的白色主画布和非常浅的灰色侧栏。
- 主要文字接近黑色，次要文字使用中性灰。
- 主操作只使用一种蓝色强调色。
- 错误和删除使用红色，但不把整页染红。
- 卡片使用淡边框、轻阴影和 12～20 像素圆角。
- 大标题清晰有力，正文保持舒适行高。
- 保留充足空白，避免仪表盘堆满信息。
- 图标必须有文字提示或可访问名称。
- 默认支持浅色模式；深色模式可以作为后续任务，但颜色变量从第一天预留。

## 3. 布局

桌面主窗口建议最小尺寸 960×640，默认尺寸约 1280×800。

- 左侧导航宽度约 240～280 像素。
- 主内容区最大阅读宽度受控，避免超宽文字行。
- 导航包含：首页、历史记录、词典。
- 设置从侧栏底部进入，可使用独立页面或窗口。
- 不显示账户头像、会员等级、升级按钮和额度卡片。

## 4. 页面要求

### 首页

- 顶部使用一句简洁产品主张。
- 今日、本周和累计数据作为主要卡片。
- 最近七天趋势保持低噪声，不使用花哨图表。
- 右侧或次级区域显示快捷键和当前模型。
- 最近记录最多展示少量条目，并提供进入历史页的入口。

### 历史记录

- 顶部为日期范围、搜索、状态和收藏筛选。
- 记录按日期分组，时间列固定且较窄。
- 正常条目突出文字，操作按钮在悬停或选中时出现。
- 失败条目显示红色短提示和主要“重试”按钮。
- 更多菜单包含下载、删除等低频操作。
- 收藏按钮应可直接点击，不藏在多层菜单中。
- 原始转录和最终文字必须有明确标签，避免用户误解。

### 词典

- 使用简洁的词语卡片或胶囊网格。
- 顶部提供搜索和“新词”按钮。
- 添加弹窗只包含单词输入、取消和确认。
- 重复词给出就地提示，不关闭弹窗。

### 设置

- 按“快捷键与录音”“模型”“输出”“数据与存储”“常规”分区。
- 标签、说明和控件保持三列对齐关系。
- 密钥输入默认遮罩，支持显示、重新输入和清除。
- 模型配置支持连接测试及清晰的成功、失败反馈。
- 数据区显示数据库与录音总占用。

### 录音胶囊

- 位于屏幕底部中央或用户可预期位置。
- 状态包括录音、转录、改写、成功和失败。
- 录音中显示时长和音量反馈，但不做复杂频谱。
- 转录与改写状态不能让用户误以为仍在录音。
- 成功后短暂消失；失败后提供打开历史的入口。
- 胶囊不能抢走目标输入框焦点。

## 5. 组件与设计变量

- 使用 CSS 变量管理颜色、圆角、阴影、间距和字体。
- 优先编写小型项目组件，不引入大型企业后台组件库。
- 所有状态组件共享同一状态色和文字规范。
- 动画时间建议在 120～240 毫秒之间，并尊重系统“减少动态效果”设置。
- 交互目标尺寸不小于 32×32 像素，关键按钮建议不小于 40 像素高。

## 6. 文案

- 使用简体中文，短句、动词开头。
- 错误提示同时回答“发生了什么”和“现在可以做什么”。
- 不使用营销夸张表达。
- 不出现与登录、会员、升级、套餐相关的文案。

## 7. 可访问性

- 所有控件可用键盘操作。
- 焦点状态清晰可见。
- 颜色不是唯一状态表达方式。
- 正文和背景满足可读对比度。
- 图标按钮提供可访问标签和悬停提示。
- 页面缩放后不丢失操作入口。

## 8. 视觉验收

- 与 Typeless 同属克制、轻量、留白充足的工具风格。
- 不包含复制的品牌元素或页面截图素材。
- 首页、历史、词典、设置和胶囊五类界面状态完整。
- 空状态、加载状态、长文本、超长词语、失败状态和小窗口均有设计。
