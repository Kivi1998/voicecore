# OpenTypeless 用户手册

> 版本：v0.9 草案（随 REL-001/REL-002 校准安装与卸载细节后定稿）

OpenTypeless 是一款本地优先的 macOS 语音输入工具：按一次快捷键开始说话，再按一次结束，应用自动完成语音识别、可选的文字改写，并把最终文字写入你当前的输入框。所有录音和文字只保存在你的 Mac 上，只发送给你自己配置的模型服务。

## 1. 系统要求

- Apple Silicon Mac（M 系列芯片）
- macOS 14 或更高版本
- 一个可用的语音识别服务账号（OpenAI 兼容接口），可选一个文字改写服务账号（OpenAI 或 Anthropic 兼容接口）

## 2. 安装

<!-- 待 REL-001/REL-002 校准：DMG 获取方式、校验值核对、首次打开（Gatekeeper）说明 -->

1. 下载 `OpenTypeless.dmg` 并打开。
2. 将 `OpenTypeless.app` 拖入「应用程序」文件夹。
3. 首次打开：在「应用程序」中右键 OpenTypeless →「打开」，在系统提示中确认。

## 3. 首次启动与权限

应用需要两项系统权限，首次启动时会引导你完成：

| 权限 | 用途 | 不授权的后果 |
| --- | --- | --- |
| 麦克风 | 录制你的语音 | 无法录音（核心功能不可用） |
| 辅助功能 | 把识别结果写入当前输入框 | 仍可识别与保存，但需从历史手动复制文字 |

授权路径：系统设置 → 隐私与安全性 → 麦克风 / 辅助功能 → 打开 OpenTypeless。授权后回到应用即可继续使用，无需重装。

## 4. 配置模型

打开「设置 → 模型」：

1. **语音识别（必需）**：添加配置，选择 OpenAI 兼容协议，填入基础地址、模型名（如 `whisper-1`）、API 密钥和超时时间，点「测试连接」确认可用后保存，并设为默认。
   - 密钥只保存在本机数据库中，界面和日志都不会显示完整密钥。
2. **文字改写（可选）**：添加 OpenAI 兼容或 Anthropic 兼容配置。不需要改写时可在「设置 → 通用」关闭改写，识别原文会直接成为最终文字。
3. 自定义基础地址仅支持 HTTPS（本机调试可用 `http://localhost`）。

连接测试不会产生历史记录，也不计入统计。

## 5. 日常使用

1. 在任意应用中把光标放到输入框。
2. 按 **⌥Space**（默认快捷键，可在设置中修改）开始录音——屏幕角落出现录音胶囊，显示录音状态与音量。
3. 说完后再按一次 **⌥Space** 结束。应用会依次完成：保存录音 → 语音识别 →（可选）改写 → 写入当前输入框。
4. 录音中再次想取消：点击录音胶囊上的停止按钮旁的取消，或按 Esc（以应用内提示为准）。

失败怎么办：

- **识别失败**（断网、超时、密钥错误）：录音和原文不丢。打开「历史」，找到该条记录，点「重新识别」。
- **改写失败**：点「仅重新改写」——不会重复上传音频。
- **写入失败**（例如目标是密码框等安全输入框）：文字已保存，点「再次输入」重试，或直接从历史复制。

## 6. 词典

「词典」页手动维护专有名词（如人名、产品名、中英混写术语）。词条会随识别和改写请求发送给模型，显著改善专有名词的识别准确率。词典为单词级手动维护，应用不会自动学习或上传你的输入历史。

## 7. 历史与统计

- **历史**：按天分组，支持搜索（原始/最终文字）、按日期范围筛选、按状态筛选。每条记录可展开查看原文与最终文字、使用的模型、时长，以及复制、下载录音、收藏、删除和按失败阶段重试。
- **下载录音**：导出 `.m4a` 文件到任意位置。
- **删除**：需二次确认，会同时删除数据库记录与录音文件，不可撤销。
- **首页**：今日、本周（周一起）、累计的识别次数与字数统计，以及最近 7 天趋势和最近记录。统计只计算成功产出文字的记录。

## 8. 数据与隐私

- 全部数据保存在本机（详见 `docs/DATA_LOCATIONS.md`），目录权限为仅当前用户可访问。
- 录音永久保留，应用**绝不自动删除**任何录音；唯一的批量删除入口在「设置 → 数据与存储 → 清理」，需你手动选择天数并二次确认。
- 音频只发送给你配置的语音识别端点；文字只发送给你配置的改写端点。应用没有任何遥测、统计上报或自动更新检查。
- 「导出历史」生成 JSON 文件，不包含 API 密钥和模型配置。

## 9. 卸载

1. 退出 OpenTypeless（菜单栏图标 → 退出）。
2. 删除「应用程序」中的 `OpenTypeless.app`。
3. 如需删除全部数据（录音、历史、配置、密钥），删除数据目录（路径见 `docs/DATA_LOCATIONS.md`）。此操作不可撤销，建议先导出历史。

遇到问题请查阅 `docs/TROUBLESHOOTING.md`。
